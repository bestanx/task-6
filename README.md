3. Работа единственного цикла for
Цикл for (int i = 0; ; i++) является бесконечным, но внутри него есть условие выхода (break). На каждой итерации происходит следующее:

А) Добавление текущего члена a в суммы:

if (i < n) s1 += a; — если мы еще не набрали n слагаемых, добавляем текущий член в первую сумму.

if (Math.abs(a) > e) s2 += a; — если модуль текущего члена больше заданной точности e, добавляем его во вторую сумму.

if (Math.abs(a) > e / 10) s3 += a; — если модуль больше e/10, добавляем в третью сумму.

Б) Проверка условия выхода из цикла:

if (i >= n - 1 && Math.abs(a) <= e / 10) break;
Цикл завершится только тогда, когда выполнятся оба условия:

Мы обработали как минимум n членов ряда (так как i начинается с 0, то i >= n - 1 означает, что мы набрали n штук).
Текущий член ряда по модулю стал меньше или равен e/10. Мы берем именно e/10, потому что это самый строгий порог из всех трех сумм. Если член ряда меньше e/10, то он точно меньше и e, и не повлияет на точность.
